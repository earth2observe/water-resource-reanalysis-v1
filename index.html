eartH2Observe Water Resource Reanalysis v1

The eartH2Observe first water resources reanalysis (WRR-tier1) multi model ensemble was produced by 8 project partners and 2 external partners. The modelling systems include four land surface models, 5 global hydrological models and a simple water balance model and covers the period 1979 -- 2012. This first version of the WRR is based on the current modelling systems of each group forced with a state-of-the-art atmospheric reanalysis. This release is meant to set a benchmark dataset for future testing. A description of the multi model ensemble can be found in earth2observe deliverable 5.1 and < href="https://essd.copernicus.org/articles/9/389/2017/">Schellekens et. al. (2017).

Schellekens, J., Dutra, E., la Torre, A.M., Balsamo, G., van Dijk, A., Weiland, F.S., Minvielle, M., Calvet, J.-C., Decharme, B., Eisner, S., 2017. A global water resources ensemble of hydrological models: The eartH2Observe Tier-1 dataset. Earth System Science Data 9, 389–413.

Model Verification Results

The multi model ensemble was verified against benchmark data for evapotranspiration, terrestrial water storage anomaly (TWSA), soil moisture index, snow water equivalent (SWE) and snow cover (SC). The verification was done with the help of the tools from The International Land Model Benchmarking Project (ILAMB, Luo et al., 2012)).
